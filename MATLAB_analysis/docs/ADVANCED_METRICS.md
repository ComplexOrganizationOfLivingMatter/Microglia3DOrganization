# Other advanced measurements

The default `paper_metrics` preset contains the measurements required for the manuscript-oriented workflow. The metrics described here are optional and are not required to reproduce the main paper analyses.

They can be enabled:

- through the advanced-metric dialog in interactive mode;
- by selecting metric identifiers in a custom configuration;
- by starting from `config/presets/all_metrics.json`.

## Distance metrics

### Mean pairwise microglial distance

Measures the mean Euclidean distance between all pairs of microglial centroids inside the analyzed unit.

Metric identifier:

```text
mean_pairwise_microglia_distance_um
```

Typical output fields include `MicrogliaDist_Mean` and `MicrogliaDist_Std`.

### Mean nearest-microglia distance

Measures the nearest-neighbor distance for each microglial centroid and summarizes the distribution.

Metric identifier:

```text
mean_nearest_microglia_distance_um
```

Typical fields include `MicrogliaDistToNearest_Mean` and `MicrogliaDistToNearest_Std`.

## Radial sphere metrics

Radial metrics describe how microglia are distributed relative to the center of a sphere.

### Mean normalized radial distance

Metric identifier:

```text
mean_radial_distance
```

Output fields:

- `MeanRadialDistance`
- `StdRadialDistance`

Distances are normalized by sphere radius where required by the calculation.

### Central-third microglial fraction

Output field:

```text
CentralThirdMicrogliaFraction
```

This is the fraction of microglial centroids located within the central third of the sphere radius. It is a proportion, not a count.

A value of zero is mathematically possible when the sphere contains microglia but none lie in the central third. Spheres without microglia should be represented as unavailable rather than interpreted as a measured zero.

## Spatial-statistics metrics

### Ripley K3 deviation

Metric identifier:

```text
ripley_k3_deviation
```

Typical output field:

```text
DeviationAreaK3
```

This summarizes the deviation of the observed 3D point pattern from the configured reference behavior across distances.

### Pair-correlation deviation

Metric identifier:

```text
pair_correlation_deviation
```

Typical fields include:

- `DeviationAreaG`
- `gMax`
- `distanceGMax`
- `gMin`
- `distanceGMin`

These values summarize differences between the observed pair-correlation function and its reference.

## Directional metrics

Directional metrics characterize anisotropy and the relation between microglial positions and plaque directions.

### Polarization

Metric identifier:

```text
polarization
```

Possible fields include random-reference summaries, depth-axis polarization and plaque-influence directions.

### Alignment

Metric identifier:

```text
alignment
```

Possible fields include:

- maximum alignment;
- direction of maximum alignment;
- cosine similarity at maximum alignment;
- depth-axis alignment;
- angle between plaque-influence and alignment directions.

Only the depth-oriented summary fields are retained for the streamlined output where surface-oriented duplicates are unnecessary:

- `Align_depth`
- `Pol_depth`
- `meanCos_depth`

## Plaque-influence metrics

Optional sphere-to-plaque fields may include:

- plaque-direction unit vectors;
- polarization and alignment relative to individual plaques;
- empirical significance values;
- angles relative to the maximum-alignment direction;
- nearest-plaque and maximum-influence flags;
- aggregate plaque-influence indices.

These fields are mainly intended for exploratory spatial analysis rather than the primary manuscript tables.

## Metric dependencies

Some advanced metrics require intermediate calculations or data generated by another metric group. The configuration validator resolves these dependencies before analysis.

When a metric group is disabled, its output columns may be removed from the final tables by `standardizeOutputTable`.

## Recommended use

For exploratory analysis:

```matlab
config = createMicrogliaConfig("all_metrics");
```

Then explicitly review:

- computational cost;
- required sample size within each sphere or region;
- interpretation of missing values;
- multiple-testing considerations in downstream statistics.

The `all_metrics` preset does not automatically activate Voronoi execution. Voronoi must be enabled separately.
