# Output tables and column dictionary

This document describes the Excel outputs generated by `MATLAB_analysis` and lists the **actual column names produced by the current code** after `standardizeOutputTable.m` is applied.

The exact set of columns depends on the enabled analyses and metric groups. Columns belonging to disabled advanced or Voronoi analyses are removed before the Excel files are written.

## General conventions

### Common identifier columns

| Column | Meaning |
|---|---|
| `FileName` | Source TIFF filename or image basename. |
| `MouseID` | Mouse identifier copied from the metadata table. |
| `Sex` | Sex recorded in the metadata table. |
| `SectionID` | Brain-section identifier. |
| `ImageID` | Image identifier within the dataset. |
| `Model` | Output model label, normally `WT` or `AD`. |
| `BregmaLevel` | Bregma group or level. |
| `CorticalRegion` | Cortical sampling region, normally `Medial` or `Lateral`. |
| `Layer` | Assigned cortical layer. `NoInfo` is used when layer assignment is unavailable. |
| `LayerInformationAvailable` | Logical flag indicating whether layer assignment is available for the image. |

### Units

| Suffix | Meaning |
|---|---|
| `_um3` | Volume in µm³. |
| `_um2` | Surface area in µm². |
| `_um` | Distance in µm. |
| `_px` | Coordinate in image pixels. |
| `_cells_mm3` | Microglial density in cells/mm³. |
| `_plaques_mm3` | Plaque density in plaques/mm³. |
| `Count` or `Number` | Number of segmented objects. |
| `Fraction` | Dimensionless fraction, usually between 0 and 1. |

All physical volumes and distances are calculated using the image calibration and the configured linear shrinkage-correction factor.

# Global image-level output

## Workbook and sheets

The global analysis writes one workbook. Its filename is defined in the configuration. The workbook can contain the following sheets:

| Sheet | Rows represented |
|---|---|
| `WT` | One row per WT image. |
| `AD` | One row per complete AD image. |
| `ADNoPlaques` | One row per AD image after excluding the dilated plaque-associated regions. |
| `ADPlaques` | One row per AD image restricted to the dilated plaque-associated regions. |

## Columns always prepared for the global table

### Identifiers

`FileName`, `MouseID`, `Sex`, `SectionID`, `ImageID`, `Model`, `BregmaLevel`, `CorticalRegion`

### Paper-oriented microglial measurements

| Column | Meaning |
|---|---|
| `TotalTissueVolume_um3` | Physical volume of the complete image stack. |
| `AnalyzedVolume_um3` | Tissue volume retained after applying the tissue mask and valid crop for microglia analysis. |
| `MicrogliaCount_AnalyzedVolume` | Number of microglial soma instances included in `AnalyzedVolume_um3`. |
| `MicrogliaDensity_AnalyzedVolume_cells_mm3` | Microglial density calculated over `AnalyzedVolume_um3`. |

### Paper-oriented plaque measurements

These columns are present for AD-derived global tables when plaque analysis is enabled.

| Column | Meaning |
|---|---|
| `TotalPlaqueCount` | Number of plaque instances in the complete image. |
| `PlaqueCount_AnalyzedVolume` | Number of plaques satisfying the microglia analyzed-volume criterion. |
| `TotalPlaqueDensity_plaques_mm3` | Total plaque count normalized by the relevant image volume. |
| `PlaqueDensity_AnalyzedVolume_plaques_mm3` | Plaque count in the analyzed volume, expressed as plaques/mm³. |
| `TotalPlaqueVolume_um3` | Sum of plaque volume in the complete image. |
| `PlaqueVolume_AnalyzedVolume_um3` | Plaque volume retained in the microglia analyzed volume. |
| `TotalPlaqueOccupiedFraction` | Fraction of the relevant volume occupied by all plaques. |
| `PlaqueOccupiedFraction_AnalyzedVolume` | Fraction of the analyzed volume occupied by plaques retained by the microglia analyzed-volume criterion. |

### Global Voronoi columns

These columns are retained only when global Voronoi metrics are enabled:

| Column | Meaning |
|---|---|
| `ValidVoronoiCellCount` | Number of Voronoi cells retained by the selected boundary criterion. |
| `MeanVoronoiNeighborCount` | Mean number of neighboring Voronoi cells. |
| `StdVoronoiNeighborCount` | Standard deviation of the Voronoi neighbor count. |
| `MeanVoronoiSurfaceArea_um2` | Mean Voronoi-cell surface area. |
| `StdVoronoiSurfaceArea_um2` | Standard deviation of Voronoi-cell surface area. |
| `MeanVoronoiVolume_um3` | Mean Voronoi-cell volume. |
| `StdVoronoiVolume_um3` | Standard deviation of Voronoi-cell volume. |
| `MeanVoronoiNeighborDistance_um` | Mean distance between neighboring Voronoi seeds. |
| `StdVoronoiNeighborDistance_um` | Standard deviation of neighboring-seed distance. |

# Cortical-layer output

## Workbook and sheets

The cortical-layer analysis writes one workbook. Depending on the selected models, regions and AD-derived masks, it can contain:

`WT_Lateral`, `WT_Medial`, `AD_Lateral`, `AD_Medial`, `ADNoPlaques_Lateral`, `ADNoPlaques_Medial`, `ADPlaques_Lateral`, `ADPlaques_Medial`

Each row represents one image.

## Identifier columns

`FileName`, `MouseID`, `Sex`, `SectionID`, `ImageID`, `Model`, `BregmaLevel`, `CorticalRegion`

## Layer availability

- Lateral cortex: `Layer1`, `Layer23`, `Layer4`, `Layer5`.
- Medial cortex: `Layer1`, `Layer23`, `Layer5`, `Layer6`.

Columns for layers that do not belong to a cortical region are not included in that region's sheet.

## Paper-oriented microglial columns

For every available layer prefix `<LAYER>`, the code produces:

| Exact pattern | Meaning |
|---|---|
| `<LAYER>Volume_um3` | Analyzed tissue volume assigned to the layer. |
| `<LAYER>MicrogliaNumber` | Number of microglial soma instances assigned to the layer. |
| `<LAYER>MicrogliaDensity_cells_mm3` | Microglial density in the layer. |

Therefore, the possible exact paper-oriented names are:

- `Layer1Volume_um3`, `Layer1MicrogliaNumber`, `Layer1MicrogliaDensity_cells_mm3`
- `Layer23Volume_um3`, `Layer23MicrogliaNumber`, `Layer23MicrogliaDensity_cells_mm3`
- `Layer4Volume_um3`, `Layer4MicrogliaNumber`, `Layer4MicrogliaDensity_cells_mm3`
- `Layer5Volume_um3`, `Layer5MicrogliaNumber`, `Layer5MicrogliaDensity_cells_mm3`
- `Layer6Volume_um3`, `Layer6MicrogliaNumber`, `Layer6MicrogliaDensity_cells_mm3`

## Paper-oriented plaque columns

For every available layer prefix `<LAYER>`, AD layer tables can contain:

| Exact pattern | Meaning |
|---|---|
| `<LAYER>Volume_Plaques` | Layer volume used for the plaque calculation. |
| `<LAYER>PlaquesNumber` | Number of plaques assigned to the layer. |
| `<LAYER>PlaqueDensity_plaques_mm3` | Plaque density in the layer. |
| `<LAYER>MeanPlaqueVolume_um3` | Mean plaque volume in the layer. |
| `<LAYER>StdPlaqueVolume_um3` | Standard deviation of plaque volume in the layer. |
| `<LAYER>MeanPlaquesRelativeVolume_um3` | Mean relative plaque-volume field generated by the current code. |

The possible prefixes are `Layer1`, `Layer23`, `Layer4`, `Layer5` and `Layer6`, subject to cortical-region availability.

## Optional layer Voronoi columns

When layer Voronoi metrics are enabled, each available layer additionally contains:

| Exact pattern | Meaning |
|---|---|
| `<LAYER>ValidMicroglia` | Number of valid Voronoi cells in the layer. |
| `<LAYER>MeanNeighs` | Mean number of Voronoi neighbors. |
| `<LAYER>StdNeighs` | Standard deviation of Voronoi-neighbor count. |
| `<LAYER>MeanSurfaceArea_um2` | Mean Voronoi-cell surface area. |
| `<LAYER>StdSurfaceArea_um2` | Standard deviation of Voronoi-cell surface area. |
| `<LAYER>MeanVolume_um3_um3` | Mean Voronoi-cell volume. This duplicated unit suffix is the exact current output name. |
| `<LAYER>StdVolume_um3_um3` | Standard deviation of Voronoi-cell volume. This duplicated unit suffix is the exact current output name. |
| `<LAYER>MeanNeighborDistance_um` | Mean neighboring-seed distance. |
| `<LAYER>StdNeighborDistance_um` | Standard deviation of neighboring-seed distance. |

When layer Voronoi is disabled, all these columns are removed before writing the workbook.


# Conditional column removal

The pipeline prepares broad tables internally and removes unused metric groups immediately before writing the Excel files.

| Configuration state | Columns removed |
|---|---|
| Global or layer Voronoi disabled | Voronoi cell-count, neighbor, surface, volume and neighbor-distance columns. |
| Plaque microglial-distance metrics disabled | Columns containing `MicrogliaDist`. |
| Sphere microglial-distance metrics disabled | Individual-sphere columns containing `MicrogliaDist`. |
| Sphere radial metrics disabled | `MeanRadialDistance`, `StdRadialDistance`, `CentralThirdMicrogliaFraction`. |
| Sphere spatial-statistics metrics disabled | `DeviationAreaK3`, `DeviationAreaG`, `gMax`, `distanceGMax`, `gMin`, `distanceGMin`. |
| Sphere directional metrics disabled | Displacement, polarity, alignment, cosine, direction-vector, influence-direction and sphere-plaque directional-significance columns. |
| Sphere Voronoi disabled | All individual and combined sphere columns containing `Voronoi`. |

The `paper_metrics` configuration therefore produces a reduced set focused on the measurements used in the manuscript, whereas `all_metrics` retains the advanced metric groups selected in that template.

# Missing and unavailable values

- `NaN` indicates that a numeric quantity could not be calculated or was not applicable.
- `NoInfo` indicates that categorical information, particularly cortical-layer assignment, was unavailable.
- `false` in `LayerInformationAvailable` means that the layer value should not be interpreted.
- A count of `0` means the analysis was performed and no qualifying objects were found.
