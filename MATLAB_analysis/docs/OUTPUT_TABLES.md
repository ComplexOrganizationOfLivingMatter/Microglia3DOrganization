# Output tables and data dictionary

This document describes the tabular outputs generated by the MATLAB analysis pipeline

## General conventions

### Identifiers

Common identifier columns include:

| Column | Meaning |
|---|---|
| `File` | Source image filename or base name |
| `Mouse` | Mouse identifier |
| `Sex` | Sex recorded in the metadata |
| `Section` | Brain-section identifier |
| `Image` | Image identifier |
| `Model` | Output model label, normally `WT` or `AD` |
| `BregmaLevel` | Bregma level or group |
| `CortexArea` | `Medial` or `Lateral` |

### Units and naming

| Term or suffix | Meaning |
|---|---|
| `Volume`, `Vol`, `VolumeTotal`, `AnalyzedVolume` | Volume in µm³ unless stated otherwise |
| `Density`, `Densitymm3` | Object count per mm³ |
| `Number`, `N_`, `n` | Number of objects |
| `Mean` | Arithmetic mean |
| `Median` | Median |
| `Std` | Standard deviation |
| `P75` | 75th percentile |
| `IQR` | Interquartile range |
| `Fraction` | Proportion between 0 and 1 |
| `PercOccupied` | Percentage of volume occupied |
| `Dist`, `Distance`, `distToBorder` | Distance in µm unless otherwise stated |
| `AnalyzedVolume` or `Valid_Volume` | Tissue volume retained after applying the mask and valid crop |

Densities are calculated as count divided by analyzed volume and converted from µm³ to mm³.

## `global_image_data.xlsx`

Each row represents one image. The workbook can contain the following sheets:

| Sheet | Data represented |
|---|---|
| `WT` | Whole valid region of WT images |
| `AD` | Whole valid region of AD images |
| `ADNoPlaques` | AD microglia outside dilated plaque-associated regions |
| `ADPlaques` | AD microglia inside dilated plaque-associated regions |

### Paper-oriented global columns

| Column | Meaning |
|---|---|
| `VolumeTotal` | Physical volume of the full image stack |
| `AnalyzedVolume` | Valid tissue volume included in the microglia analysis |
| `MicrogliaNumber` | Number of microglial soma instances in the analyzed region |
| `MicrogliaDensity` | Microglial density in cells/mm³ |
| `PlaqueNumberTotal` | Number of plaque instances in the image |
| `PlaqueNumberValid` | Number of plaque instances inside the analyzed region for microglia analysis |
| `PlaqueDensityTotal` | Total plaque count divided by total volume, plaques/mm³ |
| `PlaqueDensityValid` | PlaqueNumberValid divided by AnalyzedVolume, plaques/mm³ |
| `PlaqueVolumeOccupied_Total` | Total physical volume occupied by plaques |
| `PlaqueVolumeOccupied_Valid` | Plaque volume retained in the analyzed region for microglia analysis |
| `PlaquePercOccupied_Total` | Percentage of total volume occupied by all plaques |
| `PlaquePercOccupied_Valid` | Percentage microglia-analysis volume occupied by plaque volume |

When advanced or Voronoi metrics are enabled, the table may also include valid Voronoi-cell counts and mean or standard-deviation summaries of neighbors, surface area, volume and neighbor distance.

## `individual_plaque_data.xlsx`

Each row represents one plaque from an AD image.

### Identification and layer columns

| Column | Meaning |
|---|---|
| `IDPlaque` | Plaque identifier within the image output |
| `GlobalPlaqueID` | Plaque identifier unique across the complete output table |
| `Layer` | Assigned cortical layer, or `NoInfo` when unavailable |
| `LayerInformationAvailable` | Whether layer assignment was valid for this image |

### Plaque validity flags

| Column | Meaning |
|---|---|
| `isInsideCrop` | At least part of the plaque overlaps the valid analysis crop |
| `isCompleted` | The plaque does not touch the original image boundary |
| `isCompletedInsideCrop` | The complete plaque lies inside the valid analysis crop |

The table retains all segmented plaques. Downstream analyses can select plaques using one or more of these flags.

### Plaque and associated-microglia measurements

| Column | Meaning |
|---|---|
| `PlaqueVolume` | Total plaque volume in µm³ |
| `PlaqueVolumeValid` | Plaque volume retained within the valid analysis region |
| `NAssociatedMicroglia` | Number of microglia associated with the dilated plaque region |
| `NInsideMicroglia` | Number of microglia inside the original plaque region |
| `NAroundMicroglia` | Number of associated microglia outside the original plaque but within the dilated region |
| `MicrogliaDensityTotal` | Density of all associated microglia |
| `MicrogliaDensityInside` | Density of microglia inside the plaque region |
| `MicrogliaDensityAround` | Density of microglia in the surrounding dilated region |
| `MicrogliaDist_Mean` | Mean pairwise distance among associated microglia |
| `MicrogliaDist_Std` | Standard deviation of pairwise distances |
| `MicrogliaDistToNearest_Mean` | Mean nearest-neighbor distance among associated microglia |
| `MicrogliaDistToNearest_Std` | Standard deviation of nearest-neighbor distances |

### Position columns

| Column | Meaning |
|---|---|
| `Centroid_X`, `Centroid_Y`, `Centroid_Z` | Plaque centroid coordinates |
| `distToBorder` | Distance from the plaque centroid to the cortical surface |

Voronoi summary columns are present only when the corresponding Voronoi context is enabled.

## `cortical_layer_data.xlsx`

Each row represents one image. Data are separated by model and cortical region.

Possible sheets are:

- `WT_Lateral`
- `WT_Medial`
- `AD_Lateral`
- `AD_Medial`
- `ADNoPlaques_Lateral`
- `ADNoPlaques_Medial`
- `ADPlaques_Lateral`
- `ADPlaques_Medial`

The layer pattern is:

| Column pattern | Meaning |
|---|---|
| `LayerXVolume` | Analyzed tissue volume assigned to layer X |
| `LayerXMicrogliaNumber` | Number of microglia assigned to layer X |
| `LayerXMicrogliaDensitymm3` | Microglial density in layer X, cells/mm³ |
| `LayerX...Plaque...` | Plaque number, volume or density for layer X when plaque metrics are enabled |

Layer codes used in column names are:

- `Layer1`: Layer 1
- `Layer23`: Layer 2–3
- `Layer4`: Layer 4, lateral cortex only
- `Layer5`: Layer 5
- `Layer6`: Layer 6, medial cortex only

Advanced Voronoi summaries can add valid-cell count, neighbor, surface, volume and distance fields for each layer.

## Sphere outputs

Sphere analysis produces several workbooks for every configured plaque/non-plaque radius pair. The filenames are generated inside the corresponding radius folder.

### Image-level sphere summary

Each row represents one image and radius pair. Common fields include:

| Column | Meaning |
|---|---|
| `Volume_Total` | Total image volume |
| `Valid_Volume` | Microglia-analysis volume |
| `N_Plaques` | Number of plaques |
| `Plaque_Density` | Plaque density |
| `N_Valid_Plaques` | Number of plaques in the analyzed volume used for microglia analysis|
| `N_Valid_Microglia` | Number microglia in the analyzed volume |
| `Microglia_Density` | Global microglial density in the analyzed volume |
| `Microglia_Density_Plaque` | Microglial density in plaque-associated volume |
| `N_WT_Spheres` | Number of WT reference spheres |
| `N_NonPlaque_Spheres` | Number of AD non-plaque spheres |
| `N_Plaque_Spheres` | Number of plaque-centered spheres |
| `N_Completed_PlaqueSpheres` | Number of complete plaque-centered spheres |
| fields ending in `_AnalyzedVolume` | Measurements normalized or summarized over analyzed sphere volume |

The precise fields vary between WT and AD rows.

### Individual sphere workbook

The workbook includes the following sheets:

| Sheet | One row represents |
|---|---|
| `WTSpheres` | One WT reference sphere |
| `NonPlaqueSpheres` | One AD non-plaque sphere |
| `PlaqueSpheres` | One AD plaque-centered sphere |
| `SpherePlaqueRelation` | One relation between a sphere and a plaque |

#### Common individual sphere columns

| Column | Meaning |
|---|---|
| `IDSphere` | Sequential sphere identifier in the output table |
| `ImageSphereID` | Sphere identifier within its source image |
| `TypeSphere` | Sphere category |
| `DistToBorder` | Distance from sphere center to the cortical surface |
| `Layer` | Cortical layer assignment or `NoInfo` |
| `LayerInformationAvailable` | Whether the layer assignment is valid |
| `CentroidX`, `CentroidY`, `CentroidZ` | Sphere center |
| `nMicroglia` | Number of microglia in the sphere |
| `MicrogliaDensity` | Microglial density in the valid sphere volume |
| `SphereCompleted` | Whether the complete sphere is available inside the analyzed region |
| `VolSphere` | Valid analyzed sphere volume |
| `DistNearestPlaque` | Distance to the nearest plaque, where applicable |

#### Plaque-centered sphere columns

| Column | Meaning |
|---|---|
| `Vol_Plaque` | Volume of the plaque defining the sphere |
| `Length_Plaque` | Plaque size descriptor used by the analysis |
| `N_Microglia_Plaque` | Number of plaque-associated microglia |
| `Microglia_Density_Plaque` | Density in the plaque-associated region |
| `Microglia_Density_WP` | Density calculated with the configured plaque-region volume convention |
| `Microglia_Density_WPAM` | Density using the plaque-associated microglial convention implemented by the pipeline |
| `Plaque_Inside` | Plaque inclusion flag |
| `N_Plaques_Touching` | Number of plaques touching the sphere |
| `VolOverlap` | Overlap volume with other sphere or plaque regions |

### `SpherePlaqueRelation` sheet

Each row links one sphere to one plaque.

| Column | Meaning |
|---|---|
| `IDImage` | Source image identifier |
| `ImageSphereID` | Sphere identifier within the image |
| `IDSphere` | Sphere identifier in the sphere table |
| `IDPlaque` | Plaque identifier |
| `VolPlaque` | Plaque volume |
| `DistToPlaque` | Distance from sphere center to plaque center |
| `DistanceToPlaqueSurface` | Distance from sphere center to the plaque surface |
| `u_plaque_x/y/z` | Unit vector from the sphere toward the plaque |
| `isClosest` | Whether this plaque is the nearest plaque to the sphere |
| `isMostInfluencer` | Whether this plaque has the maximum influence score |

Directional significance and angle columns are included only when directional metrics are enabled.

### Combined sphere summary

The combined summary contains separate sheets for `WT` and `AD`.

WT rows summarize:

- analyzed WT sphere volume;
- WT sphere microglial density;
- optional WT Voronoi summaries.

AD rows summarize:

- analyzed non-plaque sphere volume;
- analyzed plaque-sphere volume;
- non-plaque and plaque-sphere microglial densities;
- overlap-volume classes;
- optional Voronoi summaries for each sphere category.

## Missing and unavailable values

- `NaN` indicates that a numerical metric is unavailable, not applicable or could not be calculated.
- `NoInfo` indicates that cortical-layer information was not available for the image.
- `false` in `LayerInformationAvailable` indicates that layer assignments must not be used for that row.
- A count of zero indicates that the analyzed unit was valid but contained no objects of that type.
