# Voronoi analysis

Voronoi analysis is an optional extension of the pipeline. It is disabled by default, is not part of `paper_metrics`, and is not offered by the interactive configuration workflow.

## Scope

Microglial centroids are treated as Voronoi seeds. The pipeline does not generate the tessellation itself; it reads externally prepared centroid and Voronoi result files and summarizes the resulting cells.

Available Voronoi measurements include:

- number of valid Voronoi cells;
- mean and standard deviation of neighbor count;
- mean and standard deviation of cell volume;
- mean and standard deviation of cell surface area;
- mean and standard deviation of distance between neighboring seeds.

## Required external inputs

A Voronoi-enabled run requires:

```json
"paths": {
  "voronoiCentroids": "/path/to/VoronoiCentroids",
  "voronoiResults": "/path/to/VoronoiResults"
}
```

The centroid files must correspond exactly to the seeds used to generate the Voronoi results. The MAT files must contain the variables and dimensions expected by the current analysis functions.

Voronoi generation and the computational Lloyd-iteration reference scale are not generated by this repository.

## Enabling Voronoi

Use a custom configuration:

```json
"voronoi": {
  "enabled": true,
  "boundaryMode": "exclude",
  "contexts": {
    "global": {"enabled": true},
    "layers": {"enabled": false},
    "spheres": {"enabled": true},
    "individualPlaques": {"enabled": false},
    "adNoPlaques": {"enabled": false},
    "adPlaques": {"enabled": false}
  }
}
```

The relevant Voronoi metric identifiers must also be selected, for example:

```text
voronoi_valid_cell_count
voronoi_mean_neighbor_count
voronoi_mean_volume_um3
voronoi_mean_surface_area_um2
voronoi_mean_neighbor_distance_um
```

The validator disables all Voronoi contexts and removes Voronoi metrics when `voronoi.enabled` is false.

## Analysis contexts

| Context | Region summarized |
|---|---|
| `global` | Whole valid image region |
| `layers` | Individual cortical layers |
| `spheres` | WT, plaque-centered or non-plaque spheres |
| `individualPlaques` | Plaque-associated local regions |
| `adNoPlaques` | AD volume outside plaque-associated regions |
| `adPlaques` | AD plaque-associated volume |

Only enable contexts for which compatible centroid and Voronoi files are available.

## Boundary handling

```json
"boundaryMode": "exclude"
```

Supported values:

- `include`: retain Voronoi cells that intersect the selected region boundary.
- `exclude`: exclude cells treated as boundary-intersecting by the current context.

Global analysis always excludes cells intersecting the outer valid-region boundary, independent of the configured mode. This avoids treating artificially truncated cells as complete cells.

## Output fields

Typical fields are:

| Field pattern | Meaning |
|---|---|
| `nVoronoi...` | Number of valid Voronoi cells |
| `meanNeighboursVoronoi...` | Mean number of neighboring cells |
| `stdNeighboursVoronoi...` | Standard deviation of neighbor count |
| `meanVolumeVoronoi...` | Mean cell volume in µm³ |
| `stdVolumeVoronoi...` | Standard deviation of cell volume |
| `meanSurfaceAreaVoronoi...` | Mean cell surface area in µm² |
| `stdSurfaceAreaVoronoi...` | Standard deviation of cell surface area |
| `meanDistanceNeighboursVoronoi...` | Mean neighboring-seed distance in µm |
| `stdDistanceNeighboursVoronoi...` | Standard deviation of neighboring-seed distance |

Suffixes identify the context, such as WT spheres, non-plaque spheres, plaque spheres or a cortical layer.

## Reproducibility recommendations

Retain together:

- the validated MATLAB configuration;
- centroid MAT files;
- Voronoi result MAT files;
- the code or software version used to generate the tessellation;
- the boundary policy;
- image calibration and correction factors.

Because Voronoi generation is external, compatibility should be tested on one image before running the complete dataset.
